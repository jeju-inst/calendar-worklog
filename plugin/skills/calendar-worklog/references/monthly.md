# 워크플로 6 — 월간 직원소통공감회의 자료

> `SKILL.md`의 설정 로드·공통 출력 규칙·보안/프라이버시·실패 처리를 그대로 적용한 상태에서 따른다. 이 파일은 해당 워크플로에 들어왔을 때만 읽는다.

## 워크플로 6: 월간 직원소통공감회의 자료 작성 (읽기·집계 전용)

**트리거 예시**: `/worklog monthly`, `이번 달 직원소통공감회의 자료 정리해줘`,
`직원소통공감회의 내 파트 초안`, `월간 회의자료 정리`

**목적**: 매월 1회 열리는 제주연구원 **직원소통공감회의 자료**(부서 전원이 각자 셀을 채우는
공유 Google Doc)에 본인 파트를 작성한다. 흩어진 활동을 종합해 "과제별 주요 추진사항 +
특이사항"으로 기록하는 **월 단위 사후 기록** 케이스다. **캘린더에 쓰지 않는 읽기·집계 전용**
워크플로이며, 산출물(초안 텍스트)은 사용자가 검토 후 직접 공유 Doc에 붙여넣는다. 어디에도
자동 전송·직접 기입하지 않는다. **전체 상세·최신 규칙은 공개 리포지토리의
<https://github.com/jeju-inst/calendar-worklog/blob/main/docs/monthly-meeting-report.md>
를 따른다** (플러그인에는 포함되지 않는 별도 문서다. 본 절은 요약).

### 단계 A. 대상 월·마감 확정
- "이번 달" → 당월(`user.timezone` 기준). 회의는 매월 1회, 회의 며칠 전 마감이 공지된다
  (예: 회의 전 영업일 15:00, 이후 PDF 최종본 변환·공지).
- Slack 스레드로 마감·문서 URL이 내려온다. 문서는 **@ji.re.kr 계정 로그인** 필요.

### 단계 B. 본인 담당 과제 확정
- monday(`진행과제보드`·과제별 보드·`전체 과제리스트`)에서 본인 담당 과제를 확정.
- **공동연구는 monday에 안 잡히는 경우가 많으므로** GD 과제 폴더 문서(`할일.md`·`CLAUDE.md`
  등, 예: 시도연 공동과제)로 보완. 과제 목록은 매월 변동됨.

### 단계 C. 소스 종합 (워크플로 5와 동일 원리, 월 범위)
과제별로 이번 달 추진사항·특이사항을 뽑는다 (가용한 소스만):
- **monday.com** — 과제별 보드/아이템의 상태·마감·업데이트
- **Slack** — 부서·센터 채널의 최근 언급·결정·특이사항 (본문은 요약, DM 원칙 동일)
- **Google Calendar** — 이번 달 회의·보고·출장 일정 (도외/해외 출장은 별도 표기)
- **GD 과제 폴더** — 과제별 `할일.md`·`CLAUDE.md` 등. 특히 monday 미포착 공동연구 확인.

### 단계 D. 본인 섹션 초안 구성 (산출 위치 2곳)
1. **지속성장연구실 → 개인(조남운) 행**: 과제별 `▫제목` + 하위 `- 세부(추진사항/특이사항)`.
2. **AI데이터연구지원센터 → "AX 시스템 구축(조남운 외)" 행**: **2단 표**(지난달 상황 |
   이번달 계획) 중 이번달 계획 칸을 채운다.
- 형식: 각 과제 `▫` 불릿 + 하위 `-` 세부. 날짜 미정은 `(N월 중)`.
- 민감 과업(`sensitivity.title_keywords`)은 세부 대신 일반화 표기 후 보고 채널 확인.

### 단계 E. 초안 제시 + 확인 (직접 쓰기 지양)
- 초안 텍스트를 제시하고 사용자 확인을 받는다.
- ⚠ **공유 문서에 프로그램으로 직접 쓰지 않는다** (타인 셀 덮어쓰기·색상 미반영 위험).
  사용자가 본인 셀에 붙여넣고, **미작성=빨간 글씨 / 작성 완료=검은색** 규칙을 직접 적용한다.
- 마감 전 체크: 본인 소관 셀 빈칸(개인 과제 행 + AX 계획 칸), 부서 외부 일정→도외/해외
  출장 누락 여부.
