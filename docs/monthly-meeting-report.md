# 월간 — 직원소통공감회의 자료 작성

매월 1회, 제주연구원 **직원소통공감회의 자료**(부서 전원이 각자 셀을 채우는 공유 Google Doc)에
본인 파트를 작성한다. 흩어진 활동을 종합해 "과제별 주요 추진사항 + 특이사항"으로 기록하는,
worklog 키트의 **월 단위 사후 기록** 케이스.

> **실측 노트(2026-08 회의분).** 문서는 "빈칸 채우기"가 아니라 **지난달 셀 내용이 그대로
> 복사돼 내려온 것을 갱신**하는 작업이다. 즉 지난달 셀은 "지난달 계획" 시제로 남아 있고,
> 이걸 **① 지난달 실적(했다/못했다로 시제 전환) + ② 이번달 계획**으로 고쳐 쓴다.
> 그래서 소스 종합은 "이번 달에 뭘 했나"뿐 아니라 **"지난달 셀에 적힌 계획이 실제로
> 이행됐나"의 대조**가 핵심이다. AX 2단 표도 두 칸이 복붙된 채 오므로 7월칸=실적, 8월칸=계획으로 분리.
> **완료 단정 주의**: 캘린더엔 "작성·검토"까지만 잡히고 "제출·발간 완료"는 안 보이는 경우가
> 많다 → 종료·납품 여부는 실측만으로 단정하지 말고 사용자에게 확인(2026-08 실제로 2건 확인받음).

## 주기
- 매월 1회. 회의 며칠 전 마감이 공지된다(예: 회의 전 영업일 15:00, 이후 PDF 최종본 변환·공지).
- 슬랙 스레드로 마감·문서 URL이 내려온다. 문서는 **@ji.re.kr 계정 로그인** 필요.

## 소스 종합 (worklog와 동일 원리)
과제별로 아래를 종합해 이번 달 추진사항·특이사항을 뽑는다.
- **monday.com** — 과제별 보드/아이템의 상태·마감·업데이트 (진행과제보드, 과제별 보드, 전체 과제리스트)
- **Slack** — 부서·센터 채널의 최근 언급·결정·특이사항
- **Google Calendar** — 이번 달 회의·보고·출장 일정 (도외/해외 출장은 별도 표기)
- **GD 프로젝트 폴더** — 과제별 `할일.md`·`CLAUDE.md` 등. 특히 **공동연구**(예: 시도연 공동과제
  `~gd2026/02.JRI_CO/...`)는 monday에 안 잡히므로 폴더 문서에서 확인.

## 산출 위치 (본인 섹션이 2곳)
1. **지속성장연구실 → 개인(조남운) 행** — 과제별 `▫제목` + `- 세부(추진사항/특이사항)`.
2. **AI데이터연구지원센터 → "AX 시스템 구축 (조남운 외)" 행** — **2단 표**(지난달 상황 | 이번달 계획).
   이번달 계획 칸을 채운다.

과제 목록(변동): 지속가능발전 평가체계 / 서귀포 지역경제(공동 이중화) / 미래기획 연구지원 플랫폼(AX) /
아트페스타인제주(공동 현혜경) / 시도연 공동연구(AI 시대와 지역사회 대응).

## 형식 규칙
- 각 과제 `▫` 불릿 + 하위 `-` 세부. 날짜 미정은 `(N월 중)`.
- **미작성 표시 = 빨간 글씨**, 작성 완료 시 **검은색으로 전환**(미작성자 식별용). 초안 단계는 빨강 유지.
- ⚠ 공유 문서라 프로그램 직접 쓰기는 지양(타인 셀 덮어쓰기·색상 미반영 위험). 초안 텍스트를
  만들어 본인이 셀에 붙여넣고 빨간색 적용하는 방식이 안전.

## 마감 전 체크
- 본인 소관 셀에 빈칸 없나(개인 과제 행 + AX 7월계획 칸).
- **부서 외부 일정 → 도외/해외 출장** 누락 확인(예: 시도연 대면회의는 도외 출장 → 확정 시 기재).
